# Resultados

Esta carpeta se genera al ejecutar el modelo.

La V0 produce:

- `resumen.json`: estado de cada escenario de días.
- `plan_N_dias.csv`: programa de inspecciones de la primera solución factible.

Los archivos generados se excluyen de Git mediante `.gitignore`.
En GitHub Actions se publican como artefactos descargables.
